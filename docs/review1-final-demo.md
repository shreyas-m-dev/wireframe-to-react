# Review 1 demo

1. Start the backend and frontend with the repository commands in `README.md`.
2. Upload a wireframe and optionally enter a styling instruction.
3. Run all stages, inspect the source and generated preview, then open each in
   Full view and use Fit, zoom, reset, Escape, and fullscreen.
4. Open Code, Schema JSON, and Validation report. Turn on Debug mode to inspect
   artifact identity, local OCR/CV diagnostics, vision state, and merge report.

The image decides layout, counts, and grouping. The optional instruction only
guides style. `Needs review` means the validation gate did not establish a
trustworthy reconstruction; it is not a success badge.
